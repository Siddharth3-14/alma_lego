# alma_lego

To run the code open the folder alma_lego

Right click and press open in terminal and type

python3 run_this.py

The code run_this.py only does the plotting. 
You can change most of it but do not touch lines which have observationManager, obsMan, function2run

To quit the plotting press 'q' or the escape button

If you are making just a change in a line of the code please put a comment next to it like ‘#change: [what was changed]; date [date of change]’. If it is a block of code. Enclose it in comments.

############# Change: [what was changed];  date: [date of change] ###########
.
.
.
Your block of code
.
.
.
#################################################

The function is that important as long as you have written a documentation for it.
Use this style of documentation https://numpy.org/doc/2.1/reference/generated/numpy.add.html
